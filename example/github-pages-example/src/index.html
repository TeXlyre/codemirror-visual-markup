CodeMirror Visual Markup Editor

One visual editing layer, pluggable markup languages. The source document stays authoritative.

Mode: visual
  • Ctrl+E toggle source and visual mode
  • Ctrl+Shift+C reveal markup
  • Ctrl+Shift+T toggle the toolbar
  • Place the cursor inside a construct to reveal its markup inline
  • Put the cursor in a table to get row and column controls in the toolbar
  • Type \ or # for autocomplete from the language package
