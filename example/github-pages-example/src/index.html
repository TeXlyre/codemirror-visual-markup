CodeMirror 6 Visual Markup Extension

GitHub npm

Interactive Demo

Try visual LaTeX and Typst editing in CodeMirror 6 below.

Mode: visual Use the editor controls to switch source/visual mode, reveal markup, and show or hide the formatting toolbar.

Features

  • Source and visual editing over the same CodeMirror document
  • Built-in visual adapters for LaTeX and Typst
  • Visual headings, emphasis, lists, colors, tables, figures, and captions
  • Interactive equations with MathLive
  • Editable table layouts with row and column controls
  • Single and compound figure layouts, including subfigures
  • Inline source reveal when the cursor enters concealed markup
  • Project-relative image resolution through a configurable resolver
  • Customizable themes and toolbar APIs

Installation

npm install codemirror-visual-markup

Usage

import { EditorState } from '@codemirror/state';
import { EditorView } from '@codemirror/view';
import { latex } from 'codemirror-lang-latex';
import { DualVisualEditor } from 'codemirror-visual-markup';
import 'codemirror-visual-markup/dist/styles.css';

const view = new EditorView({
  state: EditorState.create({
    doc: '\\section{Title}\\n\\nText with $E = mc^2$.',
    extensions: [latex()]
  })
});

const editor = new DualVisualEditor(
  document.querySelector('#editor'),
  view,
  {
    language: 'latex',
    initialMode: 'visual'
  }
);
