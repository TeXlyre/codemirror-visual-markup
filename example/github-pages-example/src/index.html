CodeMirror Visual Markup Editor

One visual editing layer for pluggable markup languages while the source document stays authoritative.

GitHub npm

Interactive Visual Editor

Switch between LaTeX and Typst, edit visual widgets directly, or toggle back to the source at any time.

Mode: visual

Visual Editor Features

  • Single document: visual widgets edit the same CodeMirror document directly.
  • Multiple languages: the same visual layer supports LaTeX and Typst language adapters.
  • Interactive math: click equations to edit them with MathLive.
  • Source access: reveal markup around the cursor or switch fully back to source mode.

Keyboard Shortcuts

Editor Controls

  • Ctrl+E - Toggle source and visual mode
  • Ctrl+Shift+C - Reveal markup
  • Ctrl+Shift+T - Toggle the toolbar

Visual Editing

  • Place the cursor inside a construct to reveal its markup inline
  • Place the cursor in a table for row and column controls
  • Type \ or # for language-package autocomplete
